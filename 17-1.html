JSON 是什么

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。它用文本描述数据， 既方便人阅读，也方便机器解析，因此常作为前后端传输数据的格式。 浏览器通过 fetch 拿到 JSON 文本后，用 JSON.parse() 转成 JavaScript 对象。

键必须用双引号

属性名只能是 "name" 这种双引号形式，不能是 name 或 'name'。

值只有 6 种类型

对象、数组、字符串、数字、布尔值、null，不支持函数、undefined、日期对象。

不允许注释和多余逗号

JSON 是纯数据，不能写 // 注释，最后一个成员后面也不能留逗号。

合法写法与常见错误

✓ 合法 JSON

{ "name": "李佳明", "age": 20, "online": true }

✗ 非法 JSON

{ name: '李佳明', // 键没引号、用了单引号 "age": 20, // 有注释 }

注意：JSON 的字符串只能用双引号，键名也必须用双引号，对象末尾不能有逗号。
