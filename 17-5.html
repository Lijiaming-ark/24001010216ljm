两种定时器

JavaScript 里有两种常用的定时器 API：setTimeout 延迟一段时间后执行一次，setInterval 每隔一段时间重复执行。 两者都会返回一个 ID，用对应的 clearTimeout / clearInterval 可以取消它们。

setTimeout

延时执行一次。常用于倒计时、提示框自动消失等场景。

var t = setTimeout(function () { console.log('2 秒后执行'); }, 2000); clearTimeout(t);

setInterval

每隔固定间隔重复执行。常用于实时时钟、轮询等场景。

var t = setInterval(function () { console.log('每秒执行一次'); }, 1000); clearInterval(t);

注意事项

返回值是一个数字 ID

浏览器里 setTimeout / setInterval 都返回整数，Node.js 中返回对象。保存下来才能 clear 掉。

setInterval 可能漂移

如果回调内部耗时很长，下一次触发会被推迟。对时间要求严格的场景用 setTimeout 递归。

闭包陷阱

循环里用 setTimeout 时，回调拿到的是循环结束后的变量值，需要 IIFE 或 let 来避免。

页面隐藏会被节流

浏览器在标签页隐藏时会把 setInterval 降到约 1 次/分钟，这是性能策略，不是 bug。

先 clear 再启动

重复点击“启动”按钮前先 clear 上一次的 ID，防止多个定时器同时跑。

内存泄漏

组件销毁/页面跳转时记得 clear，否则回调一直持有 DOM 引用，内存不会被回收。
