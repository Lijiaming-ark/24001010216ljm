创建对象的 5 种方式

对象由一组键值对组成，键是字符串或 Symbol，值可以是任意数据类型。以下是最常见的五种创建方式。

对象字面量

最常用 
const ljm_obj = {
  name: '李佳明',
  age: 20
};

用花括号直接书写键值对，键值之间用冒号分隔，多个属性用逗号分隔。

new Object()

基础 
const ljm_obj = new Object();
ljm_obj.name = '李佳明';
ljm_obj.age = 20;

先创建一个空对象，再通过点语法逐个添加属性，效果等同于对象字面量。

构造函数

进阶 
function Person(name, age) {
  this.name = name;
  this.age = age;
}
const ljm_p = new Person('李佳明', 20);

通过构造函数批量创建结构相同的对象，this 指向新创建的实例。

Object.create()

原型 
const ljm_proto = { type: '学生' };
const ljm_obj = Object.create(ljm_proto);
ljm_obj.name = '李佳明';

以指定对象作为原型创建新对象，新对象可继承原型上的属性与方法。

class 类

ES6 
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}
const ljm_p = new Person('李佳明', 20);

ES6 提供的类语法，本质是构造函数的语法糖，写法更直观清晰。

常用对象 API

    

    
这些方法都挂载在 Object 构造函数上，用于读取、合并、冻结或序列化对象。


    

      

        
        

          
Object.keys(obj)

          
返回对象自身可枚举属性名组成的数组。

        

      


      

        
        

          
Object.values(obj)

          
返回对象自身可枚举属性值组成的数组。

        

      


      

        
        

          
Object.entries(obj)

          
返回由 [键, 值] 数组成的新数组，可直接用于遍历。

        

      


      

        
        

          
Object.assign(target, source)

          
将源对象的属性复制到目标对象，返回目标对象，属于浅拷贝。

        

      


      

        
        

          
Object.freeze(obj)

          
冻结对象，之后不能添加、删除或修改属性。

        

      


      

        
        

          
obj.hasOwnProperty(key)

          
判断属性是否为对象自身属性，不会沿原型链查找。

        

      


      

        
        

          
'key' in obj

          
判断属性是否存在，包括原型链上继承来的属性。

        

      


      

        
        

          
JSON.stringify(obj)

          
把对象序列化为 JSON 字符串，常用于存储或网络传输。
